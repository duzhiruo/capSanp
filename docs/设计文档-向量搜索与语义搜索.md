# 技术设计：向量搜索与语义搜索

> **版本**：v1.0 | **日期**：2026-07-17 | **状态**：待确认

## 1. 架构总览

```
截图上传 → Agent Pipeline
  Step 1: OCR
  Step 2: LLM Insight
  Step 3: Save Memory
  Step 4: Embedding (NEW) → DashScope API → Qdrant upsert

搜索请求 → query embed → 并行 { MySQL FULLTEXT, Qdrant ANN } → RRF 融合 → 返回
```

## 2. 新增模块

### 2.1 `internal/embedding/` — Embedding Provider

```go
// Provider 生成文本向量。
type Provider interface {
    Embed(ctx context.Context, text string, textType TextType) ([]float32, error)
    EmbedBatch(ctx context.Context, texts []string, textType TextType) ([][]float32, error)
    Dimension() int
}

type TextType string
const (
    TextTypeDocument TextType = "document"
    TextTypeQuery    TextType = "query"
)
```

**DashScope 实现**使用 OpenAI 兼容 `/v1/embeddings` 端点：

```
POST https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings
Authorization: Bearer {LLM_API_KEY}

{
  "model": "text-embedding-v3",
  "input": "OCR文本 + 摘要 + 标签",
  "dimensions": 1024
}
```

- 复用现有 `LLM_API_KEY` 和 `LLM_BASE_URL`
- 新增配置：`EMBEDDING_MODEL`（默认 `text-embedding-v3`）、`EMBEDDING_DIMENSION`（默认 1024）
- EmbedBatch 支持单次最多 10 条（DashScope 限制）
- Mock 实现：返回固定维度的随机向量，用于测试

### 2.2 `internal/vectorstore/` — 向量存储抽象

```go
// VectorStore 管理向量的存储和检索。
type VectorStore interface {
    Upsert(ctx context.Context, id string, vector []float32, payload map[string]any) error
    Search(ctx context.Context, vector []float32, limit int, filter map[string]any) ([]SearchResult, error)
    Delete(ctx context.Context, id string) error
    EnsureCollection(ctx context.Context) error
    Close() error
}

type SearchResult struct {
    ID       string
    Score    float32
    Payload  map[string]any
}
```

**Qdrant 实现：**
- `github.com/qdrant/go-client` v1.18.3（gRPC）
- Collection: `screenshots`，Distance: Cosine，Size: 1024
- Payload 字段：`screenshot_id`、`device_id`、`text_preview`（截断至 200 字）
- Point ID：使用 screenshot_id 的 UUID 编码
- `EnsureCollection`：启动时检查/创建 collection

**Memory 实现：**
- 内存 map 存储向量 + 暴力余弦相似度搜索
- 用于测试，不需要 Qdrant

### 2.3 `internal/tools/embedding_tool.go` — Embedding 工具

注册为 `embedding.generate`，供 Agent Pipeline 调用：

```go
func (t *EmbeddingTool) Execute(ctx context.Context, input map[string]any) (map[string]any, error) {

```

### 2.4 Pipeline 变更 — `screenshot_organize.go`

新增第 4 步：

```go
{
    Name:       "embedding",
    ToolName:   "embedding.generate",
    BuildInput: func(rc *RunContext) map[string]any {
        ocrText, _ := rc.StepOutputs["ocr"]["ocr_text"].(string)
        summary, _ := rc.StepOutputs["llm_insight"]["summary"].(string)
        tags, _ := rc.StepOutputs["llm_insight"]["tags"].(string)
        return map[string]any{
            "screenshot_id": rc.Input["screenshot_id"],
            "device_id":     rc.Input["device_id"],
            "ocr_text":      ocrText,
            "summary":       summary,
            "tags":          tags,
        }
    },
    Timeout:    30 * time.Second,
    MaxRetries: 0,
    OnFailure:  FailSkip,  // embedding 失败不影响核心流程
}
```

## 3. 混合搜索设计

### 3.1 搜索流程

```
GET /v1/search?q=竞品定价&mode=hybrid&limit=10

1. query embed = Embed(q, TextTypeQuery)
2. 并行:
   a) keyword_results = MySQL FULLTEXT(q, limit=20)  → [{id, rank}]
   b) vector_results  = Qdrant.Search(query_embed, limit=20) → [{id, score}]
3. merged = RRF(keyword_results, vector_results, k=60)
4. 按 RRF 分数排序，取 Top-limit
5. 从 MySQL 批量加载 Screenshot 详情
6. 返回
```

### 3.2 Reciprocal Rank Fusion (RRF)

```
RRF_score(d) = Σ 1 / (k + rank_i(d))
```

- `k = 60`（标准值，平衡精确匹配和语义匹配的权重）
- 关键词命中的文档通常 rank 靠前，RRF 给予较高分
- 向量匹配的文档补充语义相关结果

### 3.3 降级策略

| 场景 | 行为 |
|------|------|
| Qdrant 不可用 | 纯关键词搜索（现有逻辑），响应头 `X-Search-Mode: keyword` |
| Embedding API 不可用 | 纯关键词搜索 |
| 两者都不可用 | Memory store 内存搜索 |
| mode=keyword | 只用 MySQL FULLTEXT |
| mode=semantic | 只用 Qdrant 向量搜索 |

### 3.4 搜索接口改造

`GET /v1/search` 新增参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `mode` | `keyword` / `semantic` / `hybrid` | `hybrid` |
| `limit` | 返回数量 | 20 |

响应新增字段：

```json
{
  "items": [...],
  "search_mode": "hybrid",
  "keyword_count": 5,
  "semantic_count": 8
}
```

## 6. Backfill 命令

`cmd/backfill/main.go`：为已有截图批量生成 embedding。

```bash
go run cmd/backfill/main.go --batch-size=10 --dry-run
```

流程：
1. 查询所有 status=organized 且未有 embedding 的截图
2. 批量取 OCR + summary + tags
3. 调用 EmbedBatch（每批 10 条）
4. 批量 Upsert 到 Qdrant
5. 输出进度和统计
