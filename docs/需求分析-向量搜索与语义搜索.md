# 需求分析：向量搜索与语义搜索

> **版本**：v1.0 | **日期**：2026-07-17 | **状态**：待确认

## 1. 背景

当前搜索使用 MySQL FULLTEXT 索引做关键词匹配。用户必须输入截图中出现过的精确关键词才能命中。PRD 中定义的四种搜索模式（主题搜索、来源搜索、时间搜索、关联搜索）中，"主题搜索"和"关联搜索"无法被关键词覆盖。

例如用户输入"上次那个竞品定价的"，当前搜索无法匹配到 OCR 文本中包含"¥299/月 专业版"的截图。需要语义搜索能力。

## 2. 目标

1. **Embedding Pipeline**：在 Agent 整理截图时自动生成文本向量，存入向量数据库
2. **语义搜索**：用户用自然语言描述即可找到语义相关的截图
3. **混合搜索**：关键词精确匹配 + 向量语义匹配，融合排序返回最优结果

## 3. 功能需求

### F-V01：Embedding 生成（Pipeline 新步骤）

**描述：** 在 `screenshot_organize` Agent Pipeline 中新增第 4 步 `embedding`，对截图的 OCR 文本 + 摘要 + 标签拼接后调用 Embedding API 生成向量。

**行为：**
- 输入：前序步骤产出的 ocr_text + summary + tags
- 调用 DashScope text-embedding-v3 生成向量（1024 维）
- 将向量写入 Qdrant
- 失败策略：`skip`（embedding 失败不影响截图整理核心流程，降级为仅关键词可搜索）

**对现有 Agent 的影响：**
- `screenshot_organize` 新增第 4 个 StepDefinition
- 新增 Tool：`embedding.generate`
- 新增 Embedding Provider（DashScope text-embedding-v3，复用现有 API Key）

### F-V02：混合搜索 API

**描述：** 改造 `GET /v1/search?q=...` 接口，同时执行关键词搜索和向量搜索，融合排序。

**搜索流程：**
1. 将用户 query 实时生成 embedding（调用同一个 Embedding Provider）
2. 并行执行：
   - MySQL FULLTEXT 关键词搜索（现有逻辑）→ 返回 Top-K 结果 + 关键词匹配分
   - Qdrant 向量近邻搜索 → 返回 Top-K 结果 + 相似度分
3. 融合排序：Reciprocal Rank Fusion (RRF) 或加权合并
4. 返回合并后的 Top-N 结果

**新增请求参数：**
- `mode`：`keyword` / `semantic` / `hybrid`（默认 `hybrid`）
- 关键词搜索保持现有行为不变

**降级策略：**
- Qdrant 不可用 → 自动降级为纯关键词搜索
- Embedding API 不可用 → 自动降级为纯关键词搜索
- 两者都不可用 → 使用 Memory store 内存搜索（已有）

### F-V03：Qdrant 向量存储

**描述：** 使用 Qdrant 作为向量数据库，Docker 部署。

**数据模型：**
- Collection：`screenshots`
- 向量维度：1024（DashScope text-embedding-v3 默认维度）
- Payload：`screenshot_id`、`device_id`、`text_preview`（用于结果展示）
- 距离度量：Cosine

**运维要求：**
- Docker Compose 新增 Qdrant 服务
- 支持 Qdrant 不存在时优雅降级（纯关键词搜索仍可用）
- 提供 backfill 命令：为已有截图批量补生成 embedding

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 性能 | 语义搜索 < 500ms（含 embedding 生成 + Qdrant 查询）|
| 成本 | DashScope text-embedding-v3 约 ¥0.0007/千 token，万级截图 embedding 成本 < ¥5 |
| 可靠性 | Qdrant 宕机不影响核心功能（上传、关键词搜索、Agent 整理）|
| 可测试 | Embedding Provider 可 mock；Qdrant 客户端可用内存实现替代 |
| 兼容 | 现有 `GET /v1/search` 无 mode 参数时行为不变（hybrid 默认）|

## 5. 不在范围内

- 图片 embedding（当前只对文本做 embedding，不对截图图像做视觉编码）
- 向量数据库集群部署 / 分片
- 前端搜索 UI 改造
- 自然语言问答（Q&A Agent）
- Embedding 模型微调
- 搜索结果高亮命中片段（语义搜索无法精确高亮）
